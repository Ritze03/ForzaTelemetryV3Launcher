# Changelog

All notable user-facing changes, newest first. Categories:

**Added** (new features),
**Fixed** (bug and behaviour fixes),
**Removed** (things taken out),
**Info** (notes worth knowing).

## 2026-10-29

### Fixed
- **Installation**: fixed an issue where installing could fail on some Rust setups.

## 2026-10-24

### Info
- **ritz-get**: the launcher can now be installed and updated through ritz-get.

## 2026-09-29

### Added
- **Automatic launch**: the launcher can start the game tool for you after a short
  countdown, and stops counting down as soon as you change a setting.

## 2026-09-28

### Fixed
- **New branches**: newly published versions now show up in the list without restarting.

## 2026-07-15

### Added
- **New look**: the launcher has a new dark design.
- **Progress bars**: you can now see how far updating and building has come.
- **Re-init Repository**: a button to start over with a fresh copy of the tool.

## 2026-06-30

### Added
- **Quick start**: the launcher can now start straight away with your last settings.

## 2026-06-29

### Fixed
- **Windows**: no extra console window appears when launching anymore.

## 2026-06-27

### Added
- **First release**: a small launcher that keeps ForzaTelemetryV3 up to date, builds it
  and starts it with one click, on Windows and Linux.
- **Version choice**: pick which version of the tool to run.
